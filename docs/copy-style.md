# 문구 스타일 가이드

기획자 검수 파일(「한 칸만 옮겼는데_화면 문구 검수_New_v2」, 수정 요청 57건)에서 정리한 규칙이에요.
방명록 · 축하 화환 · 게임 소개 페이지의 문구는 이 규칙을 따라요.

## 1. 게임 용어는 「」로 묶고, 정해진 말만 써요

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 「문서」 | 서류, 업무(문서를 가리킬 때) |
| 「양식」 | 벽, 방해물 |
| 결재 완료 · 결재된 「문서」 | 고정된 문서, 처리된 문서 |
| 같은 색 점선 칸 | 목표, 제자리 칸, 같은 색·번호의 칸 |
| 「퇴근」 칸 | 출구, EXIT |
| 나 / 신입 | 캐릭터, 플레이어 |
| 「되돌리기」 「길 찾기」 「마감 연장」 | 되돌리기 아이템, 힌트 |
| 직전 칸 · 남은 수량 · 기준(이동 횟수) | 이전 칸 · 보유 수량 · 이동 여유 |

- 설명 문장에서 용어를 처음 말할 때 「」를 붙여요. 제목과 버튼에는 붙이지 않아요.

## 2. 안내는 기능만, 정확하게

- 규칙 · 튜토리얼 · 아이템 설명에는 농담을 넣지 않아요. 무엇이 어떻게 되는지만 말해요.
  - ✗ 화면을 스와이프하면 나와 문서가 함께 한 칸 이동합니다. 업무는 신입을 항상 따라다니죠.
  - ○ 화면을 스와이프하면 나와 「문서」가 한 칸씩 함께 이동합니다.
- 예외 상황까지 분명하게 써요. (내가 막히면 「문서」도 움직이지 못해요.)
- 바뀔 수 있는 숫자 · 번호는 피해요. (튜토리얼 3을 완료하면 → 튜토리얼을 모두 완료하면)
- 규칙 문장은 합니다체, 이어지는 안내 · 알림은 해요체를 써요.

## 3. 재미는 결과 · 상황 문구에

- 웃음은 결과 화면, 알림, 인사말처럼 상황에 반응하는 짧은 말에 몰아요.
- 퇴근길 장면(막차, 버스, 노을, 저녁 약속, 사무실 불)으로 직장인 공감을 노려요.
- 해맑게 응원하는 쪽이 더 킹받아요. (아직도 퇴근은 멀었나요? → 오늘 하루도 파이팅!)
- 짧게 끊고, 말줄임은 `…` 한 글자로. (방금 이동은 없던 일로. 쉿…)

## 4. 제목은 짧은 명사구, 마침표 없이

- 완벽한 마무리 · 에이스 신입 · 문서 복구 방법 · 문서 정지시키기 · 결재는 쟤가, 퇴근은 내가
- 설명 · 알림 문장은 마침표로 끝내고, 상품 설명도 명사로 끊지 않고 문장으로 써요.
  - ✗ 다음으로 이동해야 할 방향 안내
  - ○ 다음으로 이동해야 할 방향을 알려 줘요.

## 게임 속 결과 문구 (그대로 가져다 써요)

| 별 | 제목 | 멘트 |
|---|---|---|
| 1개 | 막차 탑승 실패 | 버스는 놓쳤어도 업무는 안 놓쳤어요. |
| 1개 | 불 끄고 퇴근 | 사무실 불은 마지막 사람이 끄는 거래요. |
| 1개 | 연장 근무 완료 | 과정은… 묻지 않을게요. |
| 2개 | 저녁 약속 사수 | 약속 시간엔 늦지 않겠어요. |
| 2개 | (거의) 칼퇴근 | 노을 보면서 퇴근하는 것도 나쁘지 않죠. |
| 2개 | 한 끗 차이 | 조금만 다듬으면 에이스예요. |
| 3개 | 완벽한 마무리 | 일 잘하는 직원이 칼퇴도 쟁취하는 법. |
| 3개 | 에이스 신입 | 이렇게 잘하면 실력이 금방 늘죠. |
| 3개 | 신(神)입 | 완벽해요. 내일도 이대로 부탁해요. |
